SHADOW PROTOCOL: DISSENT

An original Commodore 64–inspired parser adventure of fictional espionage, language, counterintelligence and security ethics. By Blair Page. Everything happens inside a fictional sandbox: no live targets, real exploitation, or network access.

How to play / accessibility

Type commands such as LOOK, EXAMINE DOSSIER, TAKE BADGE, USE BADGE ON READER, GO NORTH, TALK TO ARCHIVIST, DECODE MESSAGE, AUDIT LOG, SAVE and LOAD. Press ↑ and ↓ to browse command history. Type HELP for all commands. You can finish without timing or combat.
