# SHADOW PROTOCOL: DISSENT

**An original black-and-green Commodore 64–inspired espionage and security text adventure**  
By Blair Page.

Play an analyst inside the fictional Operation GLASS ECHO training facility. Explore seven connected rooms using a classic text parser, decode a ROT13 codeword, audit a simulated access log, challenge unsupported attribution, defend lawful dissent, and submit a responsible findings report. The story explores social engineering, evidence, counterintelligence, the ethics of pentesting, narrative manipulation, and metagaming.

## Play locally

Open `index.html` in any modern browser. No installation, dependencies, backend, API keys, or external game assets.

## GitHub Pages

1. Create a **public** repository named `Shadow-Protocol-Dissent`.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/(root)`.
4. Visit `https://blairyfairy.github.io/Shadow-Protocol-Dissent/` after deployment.

## Controls

Enter commands in the terminal. Type `HELP` for full syntax. `LOOK`, `EXAMINE DOSSIER`, `TAKE BADGE`, `USE BADGE ON READER`, `GO NORTH`, `TALK TO ARCHIVIST`, `DECODE MESSAGE`, `AUDIT LOG`, `CHALLENGE CLAIM`, `DEFEND DISSENT`, `SUBMIT FINDINGS`, `SAVE`, `LOAD`, `JOURNAL`, and `MAP` are supported. Up/down arrows browse command history. Buttons provide common commands on touch devices.

## Content note

This is a fictional puzzle adventure. The terminal is not a real shell, and the security exercise does not connect to or scan any system. Its scenarios emphasize authorized testing, evidence quality, attribution uncertainty, whistleblower protection, and responsible disclosure. No third-party game graphics or code are used.
